# IPTV Android (nativo)

App direto ao ponto para S25 Ultra / Redmi Note 12 Pro.

## Funcoes
- Player HLS (ExoPlayer)
- Importar M3U do armazenamento do celular
- Playlists uma abaixo da outra
- Filtros: todos / esconder mortos / mortos / favoritos / mais assistidos
- Recarregar listas + testar sinal
- Espelhar na TV (Google Cast na mesma Wi-Fi)
- Tela cheia (gira o celular)
- Mudo
- Gestos no player: esquerda volume, direita brilho

## Build
```bat
build-apk.bat
```

APK: Desktop `IPTV-Android.apk`
